## F7编译理解


F7完成：

```
C文件
 ↓
预处理
 ↓
编译
 ↓
生成.o文件
 ↓
链接
 ↓
生成.axf文件
 ↓
生成hex文件
```


编译成功标志：

```
0 Error(s), 0 Warning(s)
```


## F8下载理解


F8会把编译生成的程序下载到STM32芯片Flash中。

下载前需要：

- ST-Link连接开发板
- Flash Download配置正确
- 编译生成axf文件


## Keil添加组件学习


添加自己的代码需要：

1. 在Keil中创建Group；

2. 添加对应的.c文件；

3. 在：

```
Options for Target
→ C/C++
→ Include Paths
```

添加头文件路径。


原因：

- .h文件负责声明函数；
- .c文件负责实现函数；
- 只有加入工程的.c文件才会参与编译。


## 遇到的问题


### 1. 找不到头文件


错误：

```
error: 'buzzer.h' file not found
```


原因：

删除了：

```
hardware/inc
```

Include Path。


解决：

重新添加：

```
..\hardware\inc
```


### 2. Undefined symbol错误


错误：

```
Undefined symbol buzzer_init
Undefined symbol led_on
```


原因：

只包含了.h文件，但是没有加入对应.c文件。


解决：

重新添加：

```
hardware/src/buzzer.c
hardware/src/led.c
```
